# Footprinting-for-website-called-www.wiley.com
------------------------------------------------

## Description
This repository contains a study on website footprinting techniques applied to www.wiley.com. The purpose of this task is **educational and research-oriented**, focusing on gathering publicly available information without attempting unauthorized access or hacking.

## What is Footprinting?
Footprinting is the process of collecting information about a target website or organization from publicly available sources. This includes:
- Domain and IP information
- Subdomains
- WHOIS records
- DNS records
- SSL certificates
- Publicly available employee or contact information

## Tools Used
- `whois`
- `nslookup`
- `dig`
- `theHarvester`
- `Recon-ng`
- Browser-based research

## Ethical Note
All information collected is publicly available. No attempts were made to access private data or perform illegal actions. This project is intended for learning and improving cybersecurity knowledge.
